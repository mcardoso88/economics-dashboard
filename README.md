# Employment Outcomes by Field of Study

An interactive, single-page dashboard for exploring labour market outcomes of Canadian bachelor's and master's degree holders by field of study. Built for the Brock University Economics department — centered on the question *"Where does Economics stand?"*

![Stack](https://img.shields.io/badge/stack-React%20%7C%20Vite%20%7C%20Tailwind%20%7C%20Recharts-000066)

## What it does

- **Overview** — rank callouts for the featured degree (Economics) vs. the top 50 most common fields at the selected degree level, across median income, average income, employment rate, and unemployment rate.
- **Field of Study Explorer** — search for any degree and see where it stands:
  - **Highlight mode:** one degree emphasized against all 50 for context.
  - **Compare mode:** pick two degrees and measure them head-to-head.
- **Charts** — horizontal bar rankings for median income and employment rate, plus a gender pay gap breakdown for the selected degree(s).
- **Filters** — swap Region (Canada / Ontario), Age (25–64, 25–34, 35–44), Gender (All / Men+ / Women+) and Degree level (Bachelor's / Master's) at any time; all charts and stats recompute live.
- **Notes** — methodology and field-selection criteria at the bottom of the page, generated from the same rules the data pipeline uses.

## Data source

Statistics Canada, 2021 Census of Population:

- [Table 98-10-0401-01](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=9810040101) — labour force status. Used to rank fields and for employment/unemployment rates.
- [Table 98-10-0409-01](https://www150.statcan.gc.ca/t1/tbl1/en/tv.action?pid=9810040901) — employment income. Median and average income for full-year, full-time workers in 2020.

**Field selection (per degree level):** the top 50 four-digit CIP 2021 fields, ranked by the *Total - Labour force status* count (everyone whose highest credential is that degree) for Canada, ages 25–64, all genders. Catch-all `xx.99` "other" fields are dropped. Law (LLB/JD, 22.01) is usually a second degree, so it is moved from the bachelor's list to the master's list. Its figures are StatCan's bachelor's-level numbers, and the `Source_Degree` column records this. Field definitions are on the [CIP Canada 2021](https://www23.statcan.gc.ca/imdb/p3VD.pl?Function=getVD&TVD=1420413) page. Rules live in `src/lib/selection.js`.

### Refreshing the data

```bash
npm run fetch-data
```

`scripts/fetch-statcan.mjs` pulls only the needed cells from the StatCan Web Data Service (the full-table downloads are 1–3 GB) and rewrites `public/top50_degrees_combined.csv`. It needs no extra dependencies, just Node 18+ and network access. The CSV is loaded at runtime with PapaParse; there is no backend.

## Tech stack

- **React 18** + **Vite 5** — fast dev server, minimal boilerplate
- **Tailwind CSS 3** — utility-first styling, Brock brand colors baked in
- **Recharts 2** — declarative, SVG-based charts
- **PapaParse 5** — CSV parsing in the browser

## Run locally

```bash

npm run dev
```

```bash

npm run preview
```

## Deploy to GitHub Pages

This repo includes a GitHub Actions workflow (`.github/workflows/deploy.yml`) that builds the site and deploys it to GitHub Pages on every push to `main`.

**Steps (one-time setup):**

1. Push this repo to GitHub.
2. In the repo settings, go to **Settings → Pages → Build and deployment**, and set **Source** to **GitHub Actions**.
3. Push to `main` — the workflow will build and deploy automatically. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

The workflow automatically sets the correct base path for assets using `VITE_BASE_PATH=/<repo-name>/`, so no manual config is needed.

## Customizing

Most things you'd want to change live in `src/lib/config.js`:

| Want to change…                  | Edit                                    |
|----------------------------------|-----------------------------------------|
| Featured degree (currently Econ) | `FEATURED_CODE`, `FEATURED_NAME`        |
| Dashboard title                  | `TITLE`, `SUBTITLE`                     |
| Default filters on load          | `DEFAULT_FILTERS`                       |
| Brand colors                     | `COLORS` + `tailwind.config.js`         |
| Degree levels, regions, ages, top-N, exclusions | `src/lib/selection.js`, then `npm run fetch-data` |
